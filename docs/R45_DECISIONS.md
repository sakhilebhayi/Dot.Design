# R-45 decisions log

Append-only. Format: `D-n (agent, date): decision. Why.` On merge conflicts keep both sides.

D-1 (coordinator, 2026-11-09): Workspace tenancy = Jetstream Team; projects stay private to the owner by default, `visibility=team` shares with the workspace. Why: matches InfoDot team sync and the brief's business-workspace model without breaking existing owner-only rows.
D-2 (coordinator, 2026-11-09): Editor is vanilla ES modules built by Vite with ONE SVG renderer for screen and export. Why: export parity, no Alpine/Livewire start-order coupling, testable pure modules.
D-3 (coordinator, 2026-11-09): Document schema lives in resources/design/document-schema.json, read by PHP and JS. Why: one source of truth, no drift.
D-4 (coordinator, 2026-11-09): No real-time co-editing, background removal, social publishing, stock photos or MP4 export; each is stated in the report as not built. Why: no honest implementation is possible on the shared host / without licences or APIs.
D-200 (engine, 2026-11-09): History entries are two references (document before/after), not command-specific inverse patches. State is immutable and shares structure, so undo restores the very same objects (exact by construction, proven by a seeded random-sequence property test) and memory stays proportional to what changed; 200 steps plus a weight cap. Server `revision` is outside history (restore keeps the live revision). Why: simplest inverse that cannot drift from the command.
D-201 (engine, 2026-11-09): Gestures (drag, resize, rotate, text session) run inside a transaction: live commands skip the byte-size check and history, and `commit` pushes ONE undo step and enforces the size limit (rolling back with an `error` event if exceeded). Why: one undo per gesture, cheap pointer-move path.
D-202 (engine, 2026-11-09): Page structure sync (create/delete/reorder) is part of the save adapter contract (`createPage`, `deletePage`, `reorderPages`, all optional); new pages carry a client id `new_xxx` until the server returns `{id, revision}`. A change the adapter cannot perform puts the state in `failed` with a clear message instead of pretending. Why: undoable page ops must still reach the server; backend agent maps these to routes. `createFetchSaveAdapter` implements the existing PUT shape (`{revision, ...payload}`).
D-203 (engine, 2026-11-09): Locked elements (and children of a locked group) refuse move/resize/rotate/remove/reorder/style/text edits and are skipped by canvas hit-testing; lock, hide, rename, duplicate and unlock still work, and layers can select them. Why: Canva-like predictability; background shapes never get dragged by accident.
D-204 (engine, 2026-11-09): Resizing text: a corner handle scales the box AND font size proportionally (never distorts glyphs); side handles change the box only; `autoFit: grow` derives height from the layout inside the same command (no top/bottom handles); `shrink` is computed at render time (effective size, stored fontSize is the maximum). Multi-selection corners are proportional when text is inside. Why: matches what designers expect and keeps export identical (layout is shared).
D-205 (engine, 2026-11-09): Strokes on shapes are inset (drawn inside the box) so the selection box equals the visual box; lines/arrows/paths are centred. Path `d` is rescaled when its box is resized (`scalePath`) because the schema stores it in the element's own box coordinates. Why: predictable geometry; no distortion after resize.
D-206 (engine, 2026-11-09): The renderer never sets a markup `style` attribute or `xml:space` via parsing: blend mode and `style` go through CSSOM, whitespace uses `xml:space` via setAttributeNS. Why: an enforced CSP without 'unsafe-inline' for styles must not break the editor. Strings produced for export still contain these attributes (they render as images).
D-207 (engine, 2026-11-09): Unsaved-work bookkeeping (autosave dirty flag, journal) is driven by a synchronous store listener, not by animation frames; batched view notifications fall back to a 120 ms timer when rAF is paused. Why: found in the browser check: in a background tab rAF never fires, so an edit made just before switching tabs could have gone unsaved.
D-208 (engine, 2026-11-09): Crash recovery journal in localStorage keyed by project/page/revision, bounded (24 entries, 2.5 MB, 600 KB/page, 30 days). A journal whose base revision is older than the server's is flagged `stale` and `studio.recovery.apply` refuses it unless `allowStale` is passed, because applying it would silently overwrite newer work. Entries identical to the server copy are discarded.
D-209 (engine, 2026-11-09): Fonts: 18 families, latin-subset woff2 from the Fontsource npm packages (build-time source only, never an app dependency, versions floating to latest at fetch time; the script is committed and re-runnable), 55 files, 1.3 MB, licences in `public/fonts/design/LICENSES.md` (SIL OFL 1.1, Permanent Marker Apache 2.0). `config/design_fonts.php` is the single list (`files` keys: `400`, `700i`). Self-hosted face name is `dd-<key>` so a visitor's local font of the same name can never substitute. Latin subset only: other scripts fall back to the stack (stated limit).
D-210 (engine, 2026-11-09): Groups nested deeper than 3 on load/paste are flattened (leaf elements lifted, offsets kept, intermediate rotation dropped) and reported, never silently emptied. Ungrouping composes the group transform (rotation, flips, opacity, hidden) into the children; group-level shadow/blend are not carried over. Why: lossless for the common case, honest for the rare one.
D-211 (engine, 2026-11-09): Input policy: wheel pans, ctrl/cmd+wheel and trackpad pinch zoom at the cursor (`prefs.wheel = 'zoom'` flips it); copy/cut/paste go through real clipboard events (paste of plain text makes a text box, of images emits `paste-files`); shortcuts act only when focus is not in a text field; cmd/ctrl + plus/minus/0/reload/new tab etc. are never prevented. One-finger drag on empty canvas pans on touch and marquee-selects with a mouse.
D-212 (engine, 2026-11-09): Icons are drawn through an injected registry (`createIconRegistry`) that accepts `resources/design/icons.json` in several tolerant shapes (a path string, `{d}`, or `{viewBox, paths:[d | {d, fill}]}`); 12 built-in own-drawn icons keep tests and the editor working until the library lands. Unknown keys render the star, never nothing.
D-213 (engine, 2026-11-09): No runtime or build dependencies were added. Vite gets one input line (`resources/js/studio/main.js`) that exports the public API; `npm run build` stays green. Design-skill note: `emil-design-eng` and `ui-ux-pro-max` are dangling symlinks in ~/.claude/skills (empty), so only `impeccable` was applied (to the on-canvas chrome: halo under frame and spacing labels for contrast on any artwork, 44 px touch hit areas, no motion).
