# R-45 decisions log

Append-only. Format: `D-n (agent, date): decision. Why.` On merge conflicts keep both sides.

D-1 (coordinator, 2026-11-09): Workspace tenancy = Jetstream Team; projects stay private to the owner by default, `visibility=team` shares with the workspace. Why: matches InfoDot team sync and the brief's business-workspace model without breaking existing owner-only rows.
D-2 (coordinator, 2026-11-09): Editor is vanilla ES modules built by Vite with ONE SVG renderer for screen and export. Why: export parity, no Alpine/Livewire start-order coupling, testable pure modules.
D-3 (coordinator, 2026-11-09): Document schema lives in resources/design/document-schema.json, read by PHP and JS. Why: one source of truth, no drift.
D-4 (coordinator, 2026-11-09): No real-time co-editing, background removal, social publishing, stock photos or MP4 export; each is stated in the report as not built. Why: no honest implementation is possible on the shared host / without licences or APIs.
D-100 (ds, 2026-11-09): Direction is "The Light Table" (DESIGN.md at the repo root, Google design.md format, lint clean). Cool near-neutral paper and ink, ONE hue (process cyan #0A6A91 light, #5CC3EE dark) for selection, focus, links and progress; the primary button is ink on paper, not the accent; the stage (--lt-stage) is a pure neutral grey in both themes. Why: the owner rejected the dark pink SaaS look and the generic reject list (cream+serif+terracotta, near-black+acid accent, hairline broadsheet, four metric tiles, floating cards); a colour-true stage is what a design tool needs; process cyan pairs with the logo's yellow as a print-process story.
D-101 (ds, 2026-11-09): Fonts: Bricolage Grotesque (display) and Atkinson Hyperlegible Next (UI), both SIL OFL 1.1, latin-subset variable woff2 self-hosted in public/fonts/ui/ (licences in LICENSE-fonts.txt), copied from the npm packages @fontsource-variable/bricolage-grotesque 5.3.0 and @fontsource-variable/atkinson-hyperlegible-next 5.3.0 (NOT added to package.json, no runtime dependency). Instrument Sans was tried first and dropped: the Impeccable detector lists it, with Inter, Geist, Space Grotesk, Plus Jakarta Sans and Mona Sans, as a converged default. Neither chosen face is used by another Dot platform.
D-102 (ds, 2026-11-09): Icons are an inline-SVG set (133 icons) read by App\Support\Ui\Icons and drawn by <x-ds.icon>: Lucide 1.70.0 (ISC, licence copied to resources/views/components/ds/icons/LICENSE-lucide.txt) plus 5 drawn here (registration, swatch, artboard, colour-bars, nib). No Material Symbols, no CDN.
D-103 (ds, 2026-11-09): Tailwind 3 stays built (Jetstream's Livewire forms and older pages use utilities) but preflight is OFF (resources/css/ds/base.css is the reset), the forms plugin is no longer loaded, and gray/indigo/red/green/yellow/rose/white/black are remapped onto the semantic tokens in tailwind.config.js, so every leftover utility follows the theme. All dark: utilities were removed from views (tokens carry dark). New work uses lt-* classes and <x-ds.*>. Why: least risk; the build contains everything pages use (verified by a render sweep test, not by assumption).
D-104 (ds, 2026-11-09): Theme = light | dark | system, stored in localStorage key dot-design-theme (same key as the previous shell), applied to <html data-theme> by public/js/ds-theme.js loaded synchronously in <head> (no inline script, CSP-clean). With nothing stored the CSS follows prefers-color-scheme. Why: no flash, no nonce needed.
